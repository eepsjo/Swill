# 失真

??? quote "QUO"
    该项目含有**内部引用**，即本网站内其他项目的引用，如果修改文件结构，请注意对应引用链接是否需要变化。

> 向着高处挣扎的本身，足以填满一个人的心灵。我们应当想象西西弗斯是幸福的。

人们普遍认为，文明的建立过程是一个不断走向真理与坦诚的史诗。然而，虚伪、装饰、欺骗和压迫、反抗、妥协才是文明史的真实。只要将目光投向最细微的人际交往与最宏大的历史进程，不难发现支撑这场宏大演出的仅仅是一套精心维护的“妥协”机制。

在社会的微观层面——社交中，妥协无处不在。对人和善客套、着重穿着外表与社交礼仪、逢年过节的送礼做客……这些被现代人斥为“虚伪”或“低效”的举止[^1]构成了日常生活的绝大部分。我们的科技水平近乎魔法，却保留着新时期时代的价值取向。人们戴上社交面具，用温和到令人作呕的言语掩盖真实的厌恶，用体面到不知所谓的仪式搁置潜在的冲突。

[^1]: 参见[从来如此，便对么？](./4.从来如此，便对么？.md)

而在宏观的社会发展中类似的妥协更是不胜枚举：奴隶制到民主体制对不同群体的放权乃至特权的立法保护、资本国家自发引入福利制度（计划经济主动吸纳市场机制）、3K 党到黑命贵、女性力量[^2]。国家的发展史就是不断做出让步、掩饰与妥协的精英阶层的屈辱史。

[^2]: 有关性权对立相关问题，请参见[从性权对立看群体进化](../25/3.从性权对立看群体进化.md)、[插排实验](./8.插排实验.md)

面对这种普遍存在于社会的妥协性，社会学家试图给出各自的解释，却往往折戟半途。“拟剧论”将这一切归结为“前台”的印象管理与面子维护，认为社交中的妥协“是为了适应环境而表演”。然而，这不过是一种同义反复的循环论证——它解释甚至教学了“人在前台如何表演”，却未能说明“前台与面子本身何以诞生”，更无法提供证明这套环境合理性的有力证据。

经济学与博弈论的“昂贵信号论”则试图将礼仪与送礼量化为传递信任的“沉没成本”。这种功利主义的视角完全建立在“信息不对称”的俗世假设之上。其有两大谬误：一，若你我在不同领域获取资源的能力本就不同，对我来说随手办到的事可能提供给你就是大恩大德，那么该如何考虑这份“人情”的真实效力呢，是从你的主观体验，还是从我（相对于你）的客观付出呢[^3]？二，若脱离既定社会框架，或站在超越性的贤者视角（信息透明）来看，或站在摆脱物欲的圣人视角（大公无私）来看，这种依赖物质消耗来证明虚无心意的行为，不过是一种冗余的浪费；换句话说，社交行为本身的合理性被这些理论选择性忽略了。

[^3]: 参见[哲学的情绪](../24/4.哲学的情绪.md)

宏观尺度的“暴力潜能论”认为，当弱势群体掌握了不可忽视的破坏能力（暴力潜能）时，统治阶级为了避免系统完全崩溃，不得不通过制度化的放权与福利来购买和平；新朝代的统治者为了延续自己的正统性又不得不继承、支付这一部分“和平的代价”，由此陷入不断妥协的深渊。但这依然不够完整——暴力潜能的分散只是外部的博弈推力，它尚未解释人类何以能够用“无形的符号与契约”去替代“有形的流血冲突”。

要彻底理解妥协性的本质，可以回到人类认知根本困境的“象、征、名”理论[^4]。在这个框架下，微观社交中的“客套”与“缓冲垫”，本质上是人类为了避免“征”与“征”之间直接碰撞带来剧烈伤害，而主动制造的“社交性失真”。我们明知对方与自己的真实心理并非如此完美，但为了避免陷入无休止的个体纷乱，双方达成默契，共同栖居于这种“用失真的名掩盖真实的征”的和平之中。

[^4]: 参见[世界纷乱的根源](../../录/8.世界纷乱的根源.md)

在宏观层面，妥协性则表现为“署名权”让渡过程中的“署名失实”。任何权力和制度的建立，都是个体为了摆脱混乱的自然状态，将自身对万物的“署名权”（定义与占有权）让渡给“大名主”的过程。但在让渡时，由于“象”蕴含着未被认知的无限之“征”（如土地不仅能耕种，还有未来的矿产与财富），大名主总是借由“名象不符”的漏洞，攫取超出授权范围的额外权益，造成了巨大的利益与权力失真。当这种失真压迫到极限、爆发为纷乱时，大名主又不得不重新抛出新的“虚假之名”（如福利、特权保护）来进行制度上的二次妥协。

因此，妥协性的本质，就是人类对待象、征时的失真。人类无法承受绝对真实（绝对的象）所带来的剧烈磨擦与混沌，只能将自己编织进由“失真之名”构成的防护网中。

而失真本身的对错则完全取决于个体对文明的妥协程度，或者说个体的失真程度。这是这篇文章中最有意思的地方：当人试图去探讨、批判“失真”本身时，所使用的工具（语言、道德、理性）本身就是文明赋予的“失真之名”。这种探讨不可避免地陷入了自指的逻辑怪圈[^5]：一个已经被“名”所重塑的主体，试图站在客观的立场去审视失真，无异于左手试图抓住右手将自己提离地面。

[^5]: 参见[雨夜](../../文/《器囚志》/又/1.雨夜.md)

一切纷乱，最终由人自己产生。当人类在自指的闭环中陷入盲目，误以为自己所掌握的那个失真、局部的“名”就是“象”的绝对全部时，认知上的谬误便诞生了。执着于将自身的谬误强加给外部世界，动用暴力或舆论去争夺绝对的署名权，这就是所有人际撕裂、社会剧变与历史纷乱的本质。纷乱的本质，即是自指所带来的谬误的本质。

但这也不意味着虚无的本质。作为生物圈的一部分、熵增的一部分，人注定要推着“失真”这块巨石一次次走向山顶[^6]。我们明知“名”永远无法直达“象”，明知所有的客套、制度与缓冲垫都带有虚假与荒谬的色彩，却依然在这个由符号与掩饰构成的世界里努力构建秩序、寻找意义。自然界的本质是叠加态，不是混乱或秩序，但这种向着高处挣扎的行为，这种在明知失真却依然选择妥协与协作的宿命，足以填满一个人的心灵。我们应当认识到自己是西西弗斯的本质。
