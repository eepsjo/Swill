# 屏蔽安全中心“自动提交样本”警告

??? bug "AAA"
    **生成式内容警告**。这意味着该项目含有由 AI/LLM 直接或间接生成的内容。请读者知悉。

要关闭 Windows 10 的“自动提交样本”功能，同时消除安全中心图标上的黄色感叹号警告，需要在注册表或组策略中将策略更改为“从不发送”（Never Send），而不是仅仅在安全中心界面中将其手动关掉。

通过策略明确指定状态后，系统会将其判定为“已由管理员配置”，安全中心便不会再将其标记为存在安全隐患。

可以使用以下两种方式之一进行配置：

## 组策略编辑器

1. 按下 `Win + R` 键，输入 `gpedit.msc` 并回车，打开“本地组策略编辑器”。
2. 依次展开左侧导航栏：
`计算机配置` -> `管理模板` -> `Windows 组件` -> `Microsoft Defender 防病毒` -> `MAPS`
3. 在右侧列表中找到并双击 **在需要进一步分析时发送文件样本**。
4. 将选项设置为 **已启用**。
5. 在左下方的“选项”下拉菜单中，选择 **从不发送**。
6. 点击“应用”，再点击“确定”。
7. 按 `Win + R` 输入 `cmd` 打开命令行，执行命令刷新策略：
```cmd
gpupdate /force
```

## 注册表编辑器

> 适用于家庭版

1. 按下 `Win + R` 键，输入 `regedit` 并回车，打开注册表编辑器。
2. 导航至以下路径：
`HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows Defender`
3. 检查右侧或左侧树状图下是否存在名为 **`Spynet`** 的项（文件夹）。
* 如果不存在：右键点击 `Windows Defender` -> **新建** -> **项**，将其命名为 `Spynet`。
4. 点击选中 `Spynet` 项，在右侧空白处右键点击 -> **新建** -> **DWORD (32 位)值**。
5. 将该 DWORD 值命名为：`SubmitSamplesConsent`。
6. 双击打开 `SubmitSamplesConsent`，将其“数值数据”修改为 **`2`**（十六进制保持不变），点击“确定”。
* *注：`2` 对应的即是组策略中的“从不发送”。*
7. 重启电脑或注销重新登录。

---

完成上述配置后：

1. 打开 Windows 安全中心，进入 **病毒和威胁防护设置**。
2. “自动提交样本”开关下方会显示一行黄字或灰字提示：“此设置由管理员管理”，且设置已被锁定在关闭/从不发送状态。
3. 任务栏的 Windows 安全中心盾牌图标上的黄色感叹号警告会随之消失。
