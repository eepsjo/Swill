# 禁用智能多宿主名称解析

“智能多宿主名称解析”（LLMNR，Link-Local Multicast Name Resolution）是微软引入 Windows 的加快 DNS 解析速度的功能，通过在所有可用的网络适配器上发送DNS请求来实现，并自动选择返回速度最快的信息。

尽管从性能角度来看，这个功能是有道理的，但它在隐私方面引入了一个问题。例如，在 Windows 连接到代理时，智能多地址名字解析可能导致 DNS 泄漏，因为请求会同时发送到所有网络适配器，所有配置的 DNS 服务器都会收到这些请求，从而获取用户访问的网站信息。

以下是在 Windows 中禁用智能多宿主名称解析的三种方法：

## 组策略编辑器

> $计算机配置 \to 管理模板 \to 网络 \to DNS客户端$

在右侧窗格中，找到并双击“禁用智能多宿主名称解析”（Turn off Multicast Name Resolution）；在弹出的窗口中，选择“已启用”（Enabled），然后点击“确定”。

## 注册表编辑器

`HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows NT\DNSClient`

在右侧窗格中，如果没有名为“EnableMulticast”的DWORD值，则需要创建一个。

右键单击空白处，选择“新建”（New），然后选择“DWORD值”（DWORD Value）。将新创建的DWORD值命名为“EnableMulticast”。

双击此值，将数值数据设置为0，然后点击“确定”。

## 命令行

CMD 或 PowerShell 输入以下命令并执行

```powershell
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows NT\DNSClient" /v "EnableMulticast" /t REG_DWORD /d 0 /f
```
