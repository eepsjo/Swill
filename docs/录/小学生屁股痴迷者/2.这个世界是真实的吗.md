# 这个世界是真实的吗

我受不了这种莫名其妙看到一个不认识的名人突然死掉的感觉。刚才我得知了一位叫猫月的吉他手去世了的消息，我很难受，我常常因此难受，不是因为她跟邦邦有关系就仿佛跟我有关系，我也不知道为什么，我只是不明白人为什么会这么脆弱。20小时前还在发有关活动的事，9小时前就由家属发布了讣告。她再也没有明天了，她的大脑再也不放电了，她失去了一切，她就在那里，一具尸体，但那里什么也没有。一个才华横溢的拥有完整人格的年轻人就这么安静的死去了，我甚至从来没听过她的歌声，而她的歌声恰恰是我唯一能听到的东西。但凡她在死前发一句“身体不大舒服”我都不会那么难受。她什么遗言都没说过吧？为什么会这样？我现在的感觉就像之前在学校听到老师突然说“张雪峰死了”一样。他们都不是我的什么熟人，他们没帮过我，我甚至从来没看过这个吉他手的任何一个视频，但我就是很难过。为什么会这样？我很懵逼，我很恍惚。为什么他们，这群生机勃勃的、充满希望的人，会跟“死”扯上关系？仿佛我忘掉许久的关于生命的话题一下子又涌入了我的脑中，给我重重一击。为什么他们会死？为什么死的这么突然？我不明白。这世界真是太荒谬了。我也不能明白为什么评论区那些人能看上去如此平静地说出“节哀”，我根本什么都说不出来，也许大家也和我一样吧。关于死亡，应该谁都有权说些什么吧？但它恰恰是我们平日里最不在意的事情。我懵逼地翻翻朋友圈，没有任何人说这件事，大家都在过着自己的生活，没有人认识她，我也不认识她。是啊，就在我打字的这段时间，又有多少人正在死去？他们的生命难道不重要吗？我简直就一直活在幻觉中。这个世界根本不是稳定的。生命到底是什么？我想，我永远也想不明白了。我好懵逼。我应该庆幸我在wowaka去世后才认识他，不然我不敢想作为一个粉丝看到他的去世我该有多难过。我时常在听着他唱歌的时候愣一下，想着，这位正在唱歌的人已经去世了七年。很懵逼，我只能说很懵逼，这些事明明很具体，但就是永远都让我感觉到很可疑，这些事明明都是不应该发生的事情呀。这个世界是真实的吗？？？
